# iMeow — Website Task List

**Reality check:** 137 sessions with 0 ATC is NOT a missing-pages problem. Missing a homepage/founder/contact page lowers conversion at the margin — it doesn't drive it to zero. Even a bare store gets some add-to-carts from 137 visits. Zero = something broken or untracked. Fix the funnel first, build trust pages second.

---

## A. Funnel — find the zero (do first)

- [ ] Tap the live ad INSIDE the TikTok app on a real phone → product page → Add to Cart → checkout → pay. Watch where it fails. (All ad traffic is in-app browsers — #1 suspect.)
- [ ] Repeat INSIDE the Instagram app.
- [ ] Repeat on desktop + mobile Safari/Chrome — is it in-app-browser-only or everywhere?
- [ ] Confirm ATC actually adds to cart — does it need a variant selected? In stock? Any JS/theme-app error?
- [ ] Check if ATC is tracked: are there real orders? Orders but 0 ATC = tracking broken, not funnel.
- [ ] Test mobile page load speed — compress hero video/images. Slow load = bounce that looks like 0 ATC.
- [ ] Compare Meta outbound link clicks vs Shopify sessions — a gap = clicks not landing.
- [ ] Confirm the ad links straight to the PRODUCT page, not homepage/collection.
- [ ] Check for a popup covering the buy button on mobile.
- [ ] Install Microsoft Clarity (free) → watch session recordings to see where people drop.
- [ ] Turn on Shop Pay + Apple/Google Pay.

## B. Product page (where ATC happens)

- [ ] Price + free shipping + 30-day guarantee above the fold
- [ ] Star rating at the top
- [ ] Proof row: HEPA · under 30dB · covers ___ sq ft · filter life
- [ ] Sticky ATC button on mobile
- [ ] Make variant selection obvious if required
- [ ] Remove the "#1 air purifier" claim

## C. Trust pages to build (help CVR, not the cause of the zero)

- [ ] Homepage
- [ ] Founder page
- [ ] Contact page
- [ ] Blog + research articles
- [ ] UGC / community wall
